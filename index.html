Independent public-data project · North Rhine-Westphalia, Germany

Three building datasets. Which differences matter?

A reproducible Python workflow comparing official, community and model-derived building outlines in two German study windows, with an interactive map for investigating differences.

  • Building a traceable municipal GIS pipeline in Python.
  • Geometry validation, spatial indexing, polygon evaluation and meaningful automated tests.
  • Working with German municipality keys and official administrative geometry.
  • Python
  • GeoPandas
  • Shapely
  • QGIS
  • Leaflet
  • Automated tests
