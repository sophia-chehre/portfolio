Projects / Independent public-data project

Reading the Dortmund city-region through open indicators

A public Python GIS project joining four regional indicators to 33 municipalities around Dortmund, with mapped results, an interactive map and a reusable GeoPackage.

Context
German municipal GIS
Place
North Rhine-Westphalia, Germany
My role
Project design, spatial analysis and interactive delivery
Tools
Python, GeoPandas, Pandas, Folium, Jupyter, QGIS

In brief

Scope
33 municipalities in the Dortmund city-region.
Sources
INKAR 2025 indicators and BKG VG250 municipal boundaries; indicators for 2023.
Workflow
Prepare indicator tables, harmonise AGS keys, join municipal geometry, compare and map indicators.
Outputs
Six notebooks, static maps, an interactive Folium map and a GeoPackage in the public repository.

A reproducible regional perspective

The project brings employment rate, five-year population change, the share of residents aged 65 and over, and the share of long-term unemployed into a consistent municipal framework. The repository exposes the notebooks and reusable spatial output so the analysis can be inspected beyond a screenshot.

What this demonstrates

  • Preparing and joining indicator tables through municipality keys.
  • Comparing municipalities in a German city-region context.
  • Delivering notebooks, thematic maps and reusable GIS data.
Method and scope
  • This is an existing public project, distinct from the new building-data comparison.
  • Indicator years and units must be read from the repository rather than inferred from the download year.
