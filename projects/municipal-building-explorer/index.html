Projects / Independent public-data project

Three building datasets. Which differences matter?

A reproducible Python workflow comparing official, community and model-derived building outlines in two German study windows, with an interactive map for investigating differences.

Context
German municipal GIS
Place
North Rhine-Westphalia, Germany
My role
Project design, spatial analysis and interactive delivery
Tools
Python, GeoPandas, Shapely, QGIS, Leaflet, Automated tests

In brief

Planning question
How does the choice of building dataset change the inventory available for a municipal analysis?
Scope
Two 2 × 2 km windows in Bochum-Langendreer and Witten, validated against official municipal boundaries and AGS keys.
Approach
Harmonise sources, select comparable objects, validate geometries and compare overlap against a dated official reference.
Delivery
Interactive map, tested Python workflow, comparison tables, source manifests and projected GIS layers.

From public source to inspectable result

  1. 1

    Integrate and validate

    Acquire ALKIS NRW, OpenStreetMap and Microsoft ML outlines. Preserve source provenance, handle projected coordinates and eight-digit municipality keys, and exclude building parts and non-building structures.

  2. 2

    Compare without hiding uncertainty

    Calculate polygon overlap, inspect lower-agreement and unpaired features, flag possible split/merge cases and test the sensitivity of the matching threshold.

  3. 3

    Deliver usable evidence

    Explore source differences on the map or download the GeoPackage, QGIS starter project, matching tables, code and validation report.

Results from the real snapshot

Bochum: 3,852 official, 2,911 OSM and 1,399 model-derived outlines; Witten: 4,739 official, 3,870 OSM and 1,394 model-derived outlines. These counts apply only to the selected windows. Different definitions, dates and geometry grouping affect the comparison.

What this demonstrates

  • Building a traceable municipal GIS pipeline in Python.
  • Geometry validation, spatial indexing, polygon evaluation and meaningful automated tests.
  • Working with German municipality keys and official administrative geometry.
  • Turning spatial analysis into a usable browser application and portable GIS output.
Method and scope
  • IoU overlap agreement is not unconditional detection accuracy; the official layer is a dated reference.
  • The Bochum window was moved to Langendreer after the initial central-city probe showed no Microsoft coverage. Selection is coverage-based, not representative of either city.
  • This project compares published model-derived outlines; it does not train a new model.
  • No confidential employer code, data or results were used.
